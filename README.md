# Контур ЖБИ — цифровой паспорт

Сайт использует макет `digital-passport-roles-mvp.html` как точную визуальную основу. Frontend запускается на React/Vite, backend — Spring Boot 4.1.1 и PostgreSQL 18.

## Запуск

1. Убедитесь, что PostgreSQL работает на `localhost:5432`, база и пользователь `postgres`, пароль `postgres`.
2. Запустите backend: `cd backend; .\mvnw.cmd spring-boot:run` (нужна Java 21).
3. Запустите frontend: `cd frontend; npm install; npm run dev`.
4. Откройте `http://localhost:5173/`. Для демонстрационных ролей ТХЗ и завода пароль `demo123`.

Первый вход ТХЗ добавляет три демонстрационных проекта в БД. Кнопка «Создать проект» создаёт новый проект. Импорт IFC4 принимает файлы до 100 МБ, включая `Telegraf_bez_arm.ifc`: извлекаются колонны, балки, плиты, стены и фундаменты, GlobalId, ExpressID, название и этаж. Пользователь выбирает элементы для отдельных паспортов. Модель сохраняется в БД как версия; повторный импорт сопоставляет элементы по GlobalId.

В проекте «Телеграф · образец IFC» уже сохранены три колонны из образца. Откройте проект, выберите конструкцию или откройте её паспорт: показывается настоящая геометрия элемента из IFC. В 3D-окне доступны вращение, масштаб, панорамирование, подгонка вида и каркас. Кнопка «Открыть 3D на весь экран» открывает тот же элемент отдельно.

Документы PDF/JPG/PNG до 10 МБ сохраняются в PostgreSQL и доступны по ссылкам из карточек. QR ведёт на постоянный URL паспорта и требует входа. Изменения проектов и события интерфейса сохраняются в PostgreSQL; сервер проверяет организацию, роль и ряд защищённых полей.

Проверка: `cd backend; .\mvnw.cmd test`, `cd frontend; npm run build; node scripts/smoke.mjs` (для браузерной проверки нужен установленный Microsoft Edge).

## Ограничения текущей реализации

Интерфейс сценариев основан на исходном HTML-макете внутри React-оболочки. Операции заказа, производства, получения и приёмки сохраняют состояние проекта, но ещё не вынесены в отдельные серверные транзакции со всеми проверками переходов и конкурирующих изменений из ТЗ. 3D-просмотрщик изолирует выбранный элемент; полноценный просмотр всей BIM-модели и извлечение свойств материалов ещё не реализованы. Камера для сканирования QR внутри сайта не подключена: код открывается стандартной камерой телефона.
